# 同步狀態定義

## 已同步

只有在以下條件同時成立時顯示：

1. Provider parser 有產生可用的最新資料。
2. 所有設定的官方來源都成功存取。
3. 所有必要來源都成功存取。

## 部分同步

以下任一情況會顯示：

- 至少一個官方來源可存取，但有其他已設定來源失敗。
- Parser 有資料可用，但來源不完整。
- 官方頁可開啟，但公開 HTML 沒有暴露足夠結構讓 parser 驗證完整模型目錄。

此狀態下仍保留 last-known-good 與必要的後備 seed，但 UI 不應把它描述成完整同步。

## 後備資料

所有官方來源都失敗，或 parser 完全無法取得可驗證資料時使用。既有 last-known-good 不應被錯誤資料覆蓋。

## 設計原則

「HTTP 200」只代表來源可存取，不代表資料已成功解析；「有模型可顯示」也不代表模型是本次同步新取得。來源存取狀態、parser 成功狀態與資料完整度應分開呈現。
